Karma mechanism: github.com/DerKevinRiehl/karma_dmapf (Kevin Riehl et al., arXiv:2604.07970) is a Python warehouse-like MAPD simulation 
GitHub
 implementing exactly the Karma conflict-resolution mechanism you designed, with kinematic/orientation-aware robots on a 2D grid picking up and dropping off tasks. 
GitHub
 Its core rule: each agent holds a non-tradeable integer Karma balance k; on a pairwise conflict the agent chosen to replan minimizes a composite cost Δ + τ·k (Δ = replanning cost increase, τ ≥ 0 = influence parameter weighting fairness vs. immediate cost, 
arxiv
 with τ≈0.5 a good balance), 
arxiv
 and credits transfer peer-to-peer so frequent replanners accumulate Karma and are less often forced to yield later — equalizing the replanning burden over time.
